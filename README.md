#  Space Shooter

A simple 2D endless space shooter made with Godot. Control your spaceship, shoot enemies, survive as long as possible, and try to beat your highest score.

##  Controls

* Left/Right Arrow Keys – Move
* Space – Shoot

##  Built With

* Godot 4
* GDScript

##  How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/himanshusapkota/space-shooter.git
   ```
2. Open the project in Godot 4.
3. Press **F5** to play.

##  Why This Fits the "Endless" Theme

This game follows the Endless theme because there is no final level or ending. Enemies continuously spawn, and the objective is to survive for as long as possible while increasing your score. The game only ends when the player is defeated, encouraging players to keep improving and achieve higher scores each run.
