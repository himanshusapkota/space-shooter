# Space Shooter

Space Shooter is a simple 2D endless shooter game made with Godot 4. The goal is to survive as long as possible by destroying enemy ships while avoiding collisions. As you survive longer, your score increases, encouraging you to beat your previous high score.

## Controls

- Left/Right Arrow Keys – Move
- Space – Shoot

## Built With

- Godot 4
- GDScript

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/himanshusapkota/space-shooter.git
   ```

2. Open the project in Godot 4.
3. Run The Game

## Gameplay

- Move your spaceship left and right.
- Shoot enemy ships before they reach you.
- Stay alive for as long as possible.
- Try to achieve the highest score.

## Why This Fits the "Endless" Theme

This game fits the Endless theme because there is no final level or ending. Enemy ships continue to spawn throughout the game, and the challenge keeps going until the player is defeated. The main objective is to survive for as long as possible and improve your score with each attempt.
